# טאב תפריט אישי

## מטרה

להציג בתוך ProCount תפריט חיטוב אישי, זמין בכל יום, בלי להפוך אותו למערכת ניהול תפריטים או לשנות את מעקב המזון הקיים.

## החלטה

נוסף טאב ניווט רביעי בשם "תפריט". זהו מסך מידע סטטי בשלב הראשון: אין בו עריכה, סימון ביצוע, או שמירה ל-Supabase.

## תוכן המסך

1. כרטיס יעדים יומי: 2,250 קלוריות, 160 גרם חלבון, 65–70 גרם שומן, ו-240–255 גרם פחמימות.
2. ארבע ארוחות בסדר היום: בוקר, צהריים, לפני אימון, וערב / אחרי אימון.
3. בכל ארוחה: אפשרות בסיס ושתי חלופות אפשריות, כולל אומדן חלבון לכל אפשרות.
4. סעיף קצר בתחתית עם כללי היום: צעדים, שקילה לפי ממוצע שבועי, ושינה.

## מימוש

- קומפוננטה מציגה בלבד חדשה תחת `src/screens/`.
- `App.jsx` מוסיף מצב מסך, כותרת, ורכיב ניווט לטאב החדש.
- אייקון inline SVG חדש מצטרף ל-`src/lib/icons.jsx`.
- אין שינוי ל-store, לסכמת הנתונים, או לקריאות Supabase.

## בדיקה

- בניית Vite מצליחה.
- בדיקות החישובים הקיימות עוברות.
- בדיקה ידנית: הטאב מופיע, נפתח מהניווט, ומכיל את כל היעדים, הארוחות והחלופות בעברית וב-RTL.
